# Changelog

### Breaking Changes 🚨

- `9657291` Remove the forecast of when the balance turns positive, with the sensor attribute `in_the_plus_from`. ([#10](https://github.com/ignazhabibi/ha-electricity-lens/pull/10))
- `f12fe04` Replace `secondary: payback` and `return` on key figure cards with the figures Payback and Return of an area, and remove the `tiles` option of earlier versions. ([#11](https://github.com/ignazhabibi/ha-electricity-lens/pull/11))

### New Features 💫

- `9657291` Turn the balance card into the Economics card: a table of each category's yearly average, saving, investment, and net, with the sums. ([#10](https://github.com/ignazhabibi/ha-electricity-lens/pull/10))
- `f12fe04` Keep key figure cards on one line with shorter texts, open an entity's dialog from its card, add `collection_key` for a date selection with its own key, and add statistics for the standing charge and the saving by solar power. All statistics are computed again on the next start. ([#11](https://github.com/ignazhabibi/ha-electricity-lens/pull/11))

### Bug Fixes 🐞

- `f12fe04` Keep layout and other options when editing history and breakdown cards, no longer round a payback below 100 % up to 100 %, and no longer count hours with costs but no comparison value as a negative saving. ([#11](https://github.com/ignazhabibi/ha-electricity-lens/pull/11))
