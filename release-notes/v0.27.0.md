# Changelog

### New Features 💫

- `5a80415` While the past is computed, the cards say how far it is, for example "Being computed … 40 %"; the balance sensor has it as its `progress` attribute. ([#24](https://github.com/ignazhabibi/ha-electricity-lens/pull/24))

### Other Changes ☀️

- `5a80415` The past is written chunk by chunk: a restart while it is computed continues where it stopped, and the recorder and memory of Home Assistant are spared. ([#24](https://github.com/ignazhabibi/ha-electricity-lens/pull/24))
- `5a80415` A new calculation rule for heat pump or electric car no longer computes the household again. ([#24](https://github.com/ignazhabibi/ha-electricity-lens/pull/24))

### Bug Fixes 🐞

- `5a80415` A change to the energy dashboard computes the PV plant, heat pump, and electric car again together with the household, so that older periods still add up. ([#24](https://github.com/ignazhabibi/ha-electricity-lens/pull/24))
- `5a80415` The solar forecast sensors appear and go with the forecast in the energy dashboard, without a reload. ([#24](https://github.com/ignazhabibi/ha-electricity-lens/pull/24))
